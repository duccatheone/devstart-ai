# Lógica de Programação

## O que é?

Lógica de programação é a forma de pensar usada para resolver problemas por meio de uma sequência clara e ordenada de passos, antes mesmo de escrever código em qualquer linguagem específica. É a base para aprender qualquer linguagem de programação.

## Conceitos básicos

### Algoritmo
Uma sequência finita de passos bem definidos para resolver um problema ou realizar uma tarefa. Uma receita de bolo, por exemplo, é um algoritmo do dia a dia.

### Fluxogramas
Representações visuais de um algoritmo, usando formas como retângulos (ações), losangos (decisões) e setas (fluxo), úteis para planejar a lógica antes de programar.

### Variáveis e tipos de dados
Todo algoritmo trabalha com dados, que podem ser de diferentes tipos: números inteiros, números decimais, textos (strings) e valores lógicos (verdadeiro/falso).

### Estruturas de decisão
Permitem que o algoritmo escolha um caminho diferente dependendo de uma condição — por exemplo, "se a senha estiver correta, libere o acesso; senão, negue".

### Estruturas de repetição
Permitem repetir uma ação várias vezes sem reescrever o mesmo passo, como somar todos os números de uma lista um por um.

### Funções e modularização
Dividir um problema grande em partes menores e reutilizáveis, cada uma responsável por uma tarefa específica — isso facilita testar, entender e corrigir o código.

## Próximos passos

Depois de entender lógica de programação, o estudante pode seguir para:

- escolher uma linguagem de programação para praticar (ex: Python);
- estudar estruturas de dados (listas, pilhas, filas);
- praticar em plataformas de exercícios de lógica.
