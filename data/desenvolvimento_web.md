# Desenvolvimento Web

## O que é?

Desenvolvimento web é a área responsável por criar sites e aplicações que rodam em um navegador. Geralmente é dividida em duas frentes principais: frontend e backend.

## Conceitos básicos

### HTML
A linguagem de marcação usada para estruturar o conteúdo de uma página web — títulos, parágrafos, imagens, links.

```html
<h1>Título da página</h1>
<p>Um parágrafo de texto.</p>
```

### CSS
Usado para estilizar o HTML — cores, espaçamentos, layout, responsividade (adaptação a diferentes tamanhos de tela).

```css
h1 {
  color: blue;
  font-size: 24px;
}
```

### JavaScript
Linguagem de programação que roda no navegador e adiciona interatividade às páginas: validação de formulários, animações, atualização de conteúdo sem recarregar a página.

### Frontend
Parte da aplicação com a qual o usuário interage diretamente — o que ele vê e clica no navegador. Construída com HTML, CSS e JavaScript (e frameworks como React, Vue ou Angular).

### Backend
Parte da aplicação que roda no servidor, fora da visão do usuário: processa dados, acessa o banco de dados e implementa as regras de negócio. Pode ser construído em várias linguagens, como Python, JavaScript (Node.js), Java, entre outras.

### API
Uma interface que permite que o frontend converse com o backend, geralmente trocando dados no formato JSON através de requisições HTTP.

## Próximos passos

Depois de entender os conceitos básicos, o estudante pode seguir para:

- praticar HTML e CSS construindo páginas estáticas simples;
- aprender um framework de frontend (ex: React);
- aprender a criar uma API simples no backend;
- estudar como conectar uma aplicação web a um banco de dados.
